# 회원가입

API URL: /api/auth/register/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP
URL 설명: 사용자가 아이디, 비밀번호, 닉네임을 입력하여 회원가입

## **기능 설명**

사용자가 아이디, 비밀번호, 닉네임을 입력하여 회원가입한다.

## **BE 구현 주의 사항**

- 아이디(username)는 중복 불가
- 닉네임도 중복 여부 정책 정하기 필요
- 비밀번호는 해시 저장 필수
- 비밀번호 정책(최소 길이, 영문/숫자 포함 여부 등) 사전 정의 필요

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json"
}
```

### **Request Body (JSON)**

```json
 {
  "username": "string",
  "password": "string",
  "nickname": "string"
}
```

### **유효성 검사 규칙**

```json
 {
  "username": "필수, 4~20자, 영문/숫자/밑줄 허용, 중복 불가",
  "password": "필수, 8자 이상",
  "nickname": "필수, 2~15자"
}
```

### **Request Body 예시**

```json
 {
  "username": "soobin22",
  "password": "soobin1234!",
  "nickname": "수빈"
}
```

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK / 201 - Created

### Response Body (JSON)

- **설명**:

```json
{
  "message": "회원가입이 완료되었습니다.",
  "data": {
    "user_id": 1,
    "username": "soobin22",
    "nickname": "수빈"
  }
}
```

## Response Body 예시

- **설명**:

```json
# 201 Created
{
  "message": "회원가입이 완료되었습니다.",
  "data": {
    "user_id": 1,
    "username": "soobin22",
    "nickname": "수빈"
  }
}

# Other Code
# 400 Bad Request
{
  "message": "입력값이 올바르지 않습니다.",
  "data": {
    "username": ["이미 사용 중인 아이디입니다."]
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**
    - 400 - 잘못된 입력값
    - 409 - 중복 아이디
    - 500 - 서버 내부 오류

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
