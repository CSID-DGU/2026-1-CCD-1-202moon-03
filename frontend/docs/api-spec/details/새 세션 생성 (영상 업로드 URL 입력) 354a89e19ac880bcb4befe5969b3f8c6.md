# 새 세션 생성 (영상 업로드/URL 입력)

API URL: /api/sessions/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP
URL 설명: 영상 URL 입력 또는 파일 업로드로 새 학습 세션 생성

## **기능 설명**

유튜브 URL, 개인 영상 파일, 또는 개인 영상 링크를 입력하여 새 학습 세션을 생성한다. 생성 직후 AI 파이프라인 처리를 비동기로 트리거한다.

## **BE 구현 주의 사항**

- source_type: "youtube_url" / "file" / "private_url"
- youtube_url인 경우 URL 유효성 검증 필수
    - 비공개/삭제된 영상 → "영상을 불러올 수 없습니다"
    - 지원하지 않는 플랫폼 → "지원하지 않는 영상 URL입니다"
- file 업로드는 multipart/form-data 사용
- 세션 생성 후 Celery task로 AI 파이프라인 비동기 실행
- ai_status 초기값: "pending"
- 파일 업로드 시 S3/MinIO presigned URL 방식 권장 (대용량 처리)

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (JSON)**

```json
─────────────────────────────
Request Body - URL 입력 (JSON)
─────────────────────────────
{
  "source_type": "youtube_url",
  "source_url": "https://www.youtube.com/watch?v=xxxxx",
  "mode": "fidget"            // "fidget" / "rain"
}

─────────────────────────────
Request Body - 파일 업로드 (multipart/form-data)
─────────────────────────────
{
  "source_type": "file",
  "file": <binary>,
  "mode": "rain"
}
```

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "message": "세션이 생성되었습니다. AI 처리를 시작합니다.",
  "data": {
    "session_id": 1,
    "title": "한국사 강의 1강",
    "ai_status": "pending",
    "mode": "fidget"
  }
}
```
