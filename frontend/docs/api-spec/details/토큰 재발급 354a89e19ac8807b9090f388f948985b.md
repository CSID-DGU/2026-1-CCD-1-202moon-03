# 토큰 재발급

API URL: /api/auth/token/refresh/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP
URL 설명: refresh 토큰으로 access 토큰 재발급

## **기능 설명**

refresh 토큰으로 새로운 access 토큰을 발급받는다.

## **BE 구현 주의 사항**

- simplejwt 기본 TokenRefreshView 활용 가능
- 블랙리스트에 등록된 refresh token은 재발급 불가

---

### **Request Body (JSON)**

```json

```

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "access": "eyJhbGci..."
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
