# 비밀번호 찾기 이메일 발송

API URL: /api/auth/password/reset-request/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

가입된 이메일로 비밀번호 재설정 링크를 발송한다.

## **BE 구현 주의 사항**

- 가입되지 않은 이메일도 동일한 성공 메시지 반환 (보안상 존재 여부 노출 금지)
- 재설정 토큰은 UUID 또는 signed token 사용, DB 또는 캐시에 저장
- 토큰 만료시간: 10분 권장
- 이메일 발송 실패 시 500 반환
