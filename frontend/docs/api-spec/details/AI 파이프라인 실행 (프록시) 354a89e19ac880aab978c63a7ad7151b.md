# AI 파이프라인 실행 (프록시)

API URL: /api/sessions/{id}/process/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP
URL 설명: AI 파이프라인 실행 요청 및 결과 DB 저장 (Celery 내부 호출)

## **기능 설명**

DRF가 FastAPI AI 서버로 영상/음성 처리를 위임한다.
처리 완료 후 자막/낙하이벤트/퀴즈를 DB에 저장한다.

## **BE 구현 주의 사항**

- 이 API는 직접 클라이언트가 호출하는 게 아닌 POST /api/sessions/ 생성 직후 Celery가 내부 호출
- FastAPI endpoint: POST /pipeline/ (file or url 전달)
- AI 서버 응답 구조: subtitles[] / fall_events[] / quizzes[] → 각각 SUBTITLE, FALL_EVENT, QUIZ 테이블 저장
- 처리 완료 시 ai_status = "done", 실패 시 "failed" 업데이트
- 타임아웃 설정 필수 (영상 길이에 따라 수분 소요 가능)

---

## FastAPI로 전달하는 payload

```json
 {
  "file": <binary> or null,
  "source_url": "string" or null,
  "language": "ko",
  "refine": true
}
```
