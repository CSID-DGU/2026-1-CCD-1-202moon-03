# 세션 삭제

API URL: /api/sessions/{id}/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: DELETE
Type: HTTP
URL 설명: 학습 세션 및 관련 데이터 삭제

## **기능 설명**

학습 세션을 삭제한다. 관련 자막/결과 데이터 cascade 삭제.

## **BE 구현 주의 사항**

- 본인 세션만 삭제 가능
- SUBTITLE, BLANK_ITEM, FALL_EVENT, QUIZ, LEARNING_RESULT, QUIZ_ATTEMPT cascade 삭제
