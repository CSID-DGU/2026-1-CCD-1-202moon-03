# 프로필 수정

API URL: /api/users/me/
App Name: Users
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: PATCH
Type: HTTP

## **기능 설명**

닉네임 또는 아바타(캐릭터)등 개인 정보를 수정한다.

## **BE 구현 주의 사항**

- 수정 가능 필드: nickname, avatar_type만 허용
- 닉네임 중복 정책 적용 (정책 결정 시)
- PATCH이므로 부분 업데이트 허용

```json
}

```

```json
 {
```

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

```json

  "message": "프로필이 수정되었습니다.",

  }
}
```
