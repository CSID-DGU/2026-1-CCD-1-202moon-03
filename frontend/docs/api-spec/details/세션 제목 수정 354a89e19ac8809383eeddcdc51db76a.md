# 세션 제목 수정

API URL: /api/sessions/{id}/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: PATCH
Type: HTTP

## **기능 설명**

학습 세션의 제목을 수정한다.

## **BE 구현 주의 사항**

- 본인 세션만 수정 가능
- title 필드만 수정 허용

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (JSON)**

```json
 {
  "title": "string"
}
```

---

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "message": "제목이 수정되었습니다.",
  "data": {
    "session_id": 1,
    "title": "수정된 제목"
  }
}
```
