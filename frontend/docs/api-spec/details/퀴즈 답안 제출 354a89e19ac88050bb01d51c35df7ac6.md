# 퀴즈 답안 제출

API URL: /api/sessions/{id}/quiz/{qid}/answer/
App Name: Quiz
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

뽀모도로 퀴즈 팝업에서 선택한 답안을 제출한다.
정답/오답 즉시 반환 및 QUIZ_ATTEMPT에 기록.

## **BE 구현 주의 사항**

- qid: [QUIZ.id](http://quiz.id/) (quiz_index 아님 주의)
- 이미 답변한 퀴즈 재제출 시 덮어쓰기 or 409 정책 결정
- 정답 여부 서버에서 판정 (answer_index 비교)
- game/end 호출 전에도 제출 가능하도록 독립 처리


## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
─────────────────────────────
Response 성공 (200 OK) — 정답
─────────────────────────────
{
  "message": "정답입니다!",
  "data": {
    "is_correct": true,
    "answer_index": 2,
    "explanation": "고려의 수도는 개경(개성)입니다."
  }
}

─────────────────────────────
Response 성공 (200 OK) — 오답
─────────────────────────────
{
  "message": "오답입니다.",
  "data": {
    "is_correct": false,
    "answer_index": 0,
    "explanation": "고려의 수도는 개경(개성)입니다."
  }
}
```
