# (NEW) 유튜브 URL 스트리밍

API URL: /api/sessions/stream/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

유튜브 URL을 AI 서버로 전달하고, 챕터별로 처리 완료되는 즉시 SSE(Server-Sent Events)로 프론트에 스트리밍 전달한다. 전체 처리를 기다리지 않고 첫 챕터 완료 시 즉시 재생 시작 가능.

## **BE 구현 주의 사항**

- DRF는 프록시 역할 — AI 서버(`POST /api/process-url/stream`)로 요청을 전달하고 응답을 그대로 SSE로 프론트에 중계
- SSE 필수 헤더: `Cache-Control: no-cache`, `X-Accel-Buffering: no`
- 일반 `error_response()` 사용 불가 — 에러도 SSE 형식(`data: {"type": "error"}`)으로 반환
- AI 서버 주소: `.env`의 `AI_SERVER_URL` 환경변수로 관리

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body 예시 (JSON)**

```json
{
  "url": "https://www.youtube.com/watch?v=xoInosq3JBE",
  "language": "ko"
}
```

### SSE 이벤트 형식 (Response Body 예시)

```json
 # 이벤트 1 — 초기화
data: {"type": "init", "total_duration": 2400, "chapters": [{"title": "고려 중기 정치", "start_sec": 0, "end_sec": 720}]}

# 이벤트 2~N — 챕터별 데이터
data: {"type": "chapter_ready", "chapter_index": 0, "segments": [...], "fall_events": [...], "quizzes": [...]}

# 마지막 — 완료
data: {"type": "complete", "stats": {"total_segments": 587, "total_quizzes": 12}}

# 에러
data: {"type": "error", "message": "AI 서버 응답 시간이 초과되었습니다."}
```

### 비고

- **설명**: 프론트엔드/백엔드 공유 특이사항, ToDo, 추가 설명 등
- **기입 내용**:
    - EventSource API 대신 `fetch + ReadableStream` 사용 권장 (Authorization 헤더 전송 필요)
    - 첫 번째 `chapter_ready` 이벤트 수신 시 즉시 재생 시작
    - 프론트 구현 예시: (이 부분은 GPT한테 물어봤습니당)
    
    ```json
    const response = await fetch("/api/sessions/stream/", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${accessToken}`,
      },
      body: JSON.stringify({ url: youtubeUrl, language: "ko" }),
    })
    const reader = response.body.getReader()
    const decoder = new TextDecoder()
    
    while (true) {
      const { done, value } = await reader.read()
      if (done) break
      const lines = decoder.decode(value).split("\n").filter(l => l.startsWith("data: "))
      for (const line of lines) {
        const data = JSON.parse(line.replace("data: ", ""))
        if (data.type === "chapter_ready" && data.chapter_index === 0) startPlayback()
      }
    }
    ```
