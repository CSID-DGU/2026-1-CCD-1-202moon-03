# 회원 탈퇴

API URL: /api/users/me/
App Name: Users
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: DELETE
Type: HTTP

## **기능 설명**

비밀번호 재확인 후 회원 탈퇴 처리한다. 관련 데이터는 소프트 딜리트 처리한다.

## **BE 구현 주의 사항**

- 탈퇴 재확인을 위해 비밀번호를 body로 받아 검증
- USER 테이블 소프트 딜리트 (is_active=False) 권장
- 관련 VIDEO_SESSION, LEARNING_RESULT 등 cascade 정책 결정 필요
- 탈퇴 후 해당 JWT 즉시 무효화

## **Request (요청)**

### **Headers**

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (JSON)**

```json
 {
  "password": "string"
}

```
