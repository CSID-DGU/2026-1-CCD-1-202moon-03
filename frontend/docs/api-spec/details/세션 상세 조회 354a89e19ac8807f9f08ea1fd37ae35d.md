# 세션 상세 조회

API URL: /api/sessions/{id}/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP
URL 설명: 특정 학습 세션 상세 조회

## **기능 설명**

특정 세션의 상세 정보를 조회한다. 자막/낙하이벤트/퀴즈 데이터 포함.

## **BE 구현 주의 사항**

- 본인 세션만 조회 가능
- ai_status가 done이 아닌 경우에도 조회 가능 (상태 확인용)
- 데이터 크기가 크므로 자막/이벤트는 페이지네이션 또는 한 번에 전달 정책 결정

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK
- **설명**:

```json
{
  "message": "세션 조회 성공",
  "data": {
    "session_id": 1,
    "title": "한국사 강의 1강",
    "source_type": "youtube_url",
    "source_url": "https://...",
    "thumbnail_url": "https://...",
    "duration_sec": 3600.0,
    "mode": "fidget",
    "ai_status": "done",
    "created_at": "2025-04-01T12:00:00Z"
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    
    ```json
    # 404 Not Found
    {
      "message": "세션을 찾을 수 없습니다.",
      "data": {}
    }
    
    # 403 Forbidden
    {
      "message": "접근 권한이 없습니다.",
      "data": {}
    }
    ```
