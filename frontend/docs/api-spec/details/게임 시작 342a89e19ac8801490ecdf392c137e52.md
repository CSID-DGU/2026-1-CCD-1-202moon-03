# 게임 시작

API URL: /api/sessions/{id}/game/start/
App Name: Game
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP
URL 설명: 게임 시작 및 전체 학습 데이터 반환

## **기능 설명**

모드(피젯/집중호우)로 진입 시 게임에 필요한 전체 데이터를 한 번에 반환한다.
자막, 낙하 이벤트, 퀴즈 데이터 포함.

## **BE 구현 주의 사항**

- ai_status가 done인 세션만 게임 시작 가능
- 자막/낙하이벤트/퀴즈 데이터를 한 번에 모두 반환 (매 프레임 API 호출 방지)
- 피젯 모드: subtitles + quizzes 반환
- 집중호우 모드: subtitles + fall_events + quizzes 반환
- 프론트에서 fall_start_time, fall_duration 직접 계산 (AI 명세서 기준)

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    - 400 - 잘못된 모드 값
    - 401 - 인증 필요
    - 404 - 세션 없음
    
    ```json
    # 400 Bad Request - AI 처리 미완료
    {
      "message": "AI 처리가 완료되지 않았습니다.",
      "data": {
        "ai_status": "processing"
      }
    }
    
    # 404 Not Found
    {
      "message": "세션을 찾을 수 없습니다.",
      "data": {}
    }
    ```
