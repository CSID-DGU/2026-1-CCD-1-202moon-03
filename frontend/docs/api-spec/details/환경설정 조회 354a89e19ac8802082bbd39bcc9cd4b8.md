# 환경설정 조회

API URL: /api/users/me/settings/
App Name: Users
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP

## **기능 설명**

피젯 스피너/키캡 전환키 등 환경설정을 조회한다.

## **BE 구현 주의 사항**

- USER_SETTING은 회원가입 시 기본값으로 자동 생성
- 기본값: fidget_toggle_key = "alt"
