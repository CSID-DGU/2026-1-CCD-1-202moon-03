# 로그인

API URL: /api/auth/login/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

아이디와 비밀번호를 입력받아 로그인한다.

## **BE 구현 주의 사항**

- JWT 기반인지 세션 기반인지 먼저 확정 필요
- 액세스 토큰/리프레시 토큰 구조 정하기
- 로그인 실패 횟수 제한 여부 검토 필요

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json"
}
```

### **Request Body (JSON)**

```json
 {
  "username": "string",
  "password": "string"
}
```

### **유효성 검사 규칙**

```json
 {
  "username": "필수",
  "password": "필수"
}
```

### **Request Body 예시**

```json
 {
  "username": "soobin22",
  "password": "soobin1234!"
}
```

---

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

### Response Body (JSON)

- **설명**:

```json
{
  "message": "로그인에 성공했습니다.",
  "data": {
    "user_id": 1,
    "username": "soobin22",
    "nickname": "수빈",
    "access_token": "string",
    "refresh_token": "string"
  }
}
```

## Response Body 예시

- **설명**:

```json
# 200 OK
{
  "message": "로그인에 성공했습니다.",
  "data": {
    "user_id": 1,
    "username": "soobin22",
    "nickname": "수빈",
    "access_token": "eyJhbGciOi...",
    "refresh_token": "eyJhbGciOi..."
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    - 400 - 잘못된 요청
    - 401 - 아이디 또는 비밀번호 불일치
    - 500 - 서버 내부 오류
    
    ```json
    {
      "message": "아이디 또는 비밀번호가 올바르지 않습니다.",
      "data": {}
    }
    ```
