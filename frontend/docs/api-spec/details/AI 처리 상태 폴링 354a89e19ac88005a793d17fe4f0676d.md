# AI 처리 상태 폴링

API URL: /api/sessions/{id}/status/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP
URL 설명: AI 처리 상태 조회 (폴링용)

## **기능 설명**

AI 파이프라인 처리 상태를 확인한다. 프론트에서 주기적으로 폴링하여 완료 여부 확인

## **BE 구현 주의 사항**

- ai_status: pending / processing / done / failed
- 폴링 주기는 프론트에서 결정 (3~5초 권장)
- failed 시 error_message 함께 반환

---

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "message": "상태 조회 성공",
  "data": {
    "session_id": 1,
    "ai_status": "processing"
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    
    ```json
    # done 상태
    {
      "message": "상태 조회 성공",
      "data": {
        "session_id": 1,
        "ai_status": "done"
      }
    }
    
    # failed 상태
    {
      "message": "상태 조회 성공",
      "data": {
        "session_id": 1,
        "ai_status": "failed",
        "error_message": "STT 처리 중 오류가 발생했습니다."
      }
    }
    ```
