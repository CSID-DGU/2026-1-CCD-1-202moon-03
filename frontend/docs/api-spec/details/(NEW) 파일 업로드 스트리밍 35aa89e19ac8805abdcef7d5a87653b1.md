# (NEW) 파일 업로드 스트리밍

API URL: /api/sessions/stream/file/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

로컬 영상/음성 파일(mp4, mp3, webm 등)을 AI 서버로 전달하고, 챕터별로 처리 완료되는 즉시 SSE로 프론트에 스트리밍 전달한다.

## **BE 구현 주의 사항**

- `multipart/form-data`로 파일 수신 후 AI 서버(`POST /api/process/stream`)로 전달
- SSE 필수 헤더: `Cache-Control: no-cache`, `X-Accel-Buffering: no`
- 에러도 SSE 형식으로 반환
- 대용량 파일 타임아웃 주의 (`.env`의 `AI_SERVER_TIMEOUT` 설정값 따름)

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (multipart/form-data)**

```json
 file:     <binary>   ← 영상/음성 파일 (필수)
language: "ko"       ← 언어 코드 (선택, 기본값 ko)
```

### **Request Body 예시**

```json
 file: lecture.mp4
language: ko
```

---

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

### Response Body (JSON)

- **설명**:

```json
# 유튜브 스트리밍과 동일한 SSE 형식
data: {"type": "init", "total_duration": 1800, "chapters": [...]}
data: {"type": "chapter_ready", "chapter_index": 0, "segments": [...], "fall_events": [...], "quizzes": [...]}
data: {"type": "complete", "stats": {...}}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    
    ```json
    # 400 - 파일 미첨부
    data: {"type": "error", "message": "파일을 업로드해주세요."}
    
    # 500 - AI 서버 오류
    data: {"type": "error", "message": "AI 서버 오류: 500"}
    ```
