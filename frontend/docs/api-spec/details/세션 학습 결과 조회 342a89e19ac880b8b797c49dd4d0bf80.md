# 세션 학습 결과 조회

API URL: /api/sessions/{id}/result/
App Name: Analytic
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP
URL 설명: 세션 학습 결과 조회 (결과 화면)

## **기능 설명**

게임 종료 후 학습 결과 화면에서 점수/콤보/정확도/완료율/AI 요약을 조회한다.

## **BE 구현 주의 사항**

- LEARNING_RESULT + ai_summary 함께 반환
- 모드별 표시 항목 다름:
    - 피젯: watch_rate + quiz 결과 + ai_summary
    - 집중호우: watch_rate + total_score + max_combo + typing_accuracy + quiz 결과 + ai_summary
- ai_summary는 VIDEO_SESSION.ai_summary 필드 사용 (별도 AI 호출 없이)
