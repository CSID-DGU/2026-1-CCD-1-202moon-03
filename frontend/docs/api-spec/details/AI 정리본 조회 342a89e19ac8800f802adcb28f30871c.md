# AI 정리본 조회

API URL: /api/sessions/{id}/summary/
App Name: Analytic
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP
URL 설명: AI 구조화 요약 조회 (캐싱 적용)

## **기능 설명**

GPT가 생성한 강의 구조화 요약(AI 정리본)을 반환한다.
이미 생성된 경우 캐시(VIDEO_SESSION.ai_summary) 반환, 없으면 AI 서버에 재요청.

## **BE 구현 주의 사항**

- 기능명세서 6.2.1: GPT API 활용한 전체 내용 구조화 요약
- ai_summary가 VIDEO_SESSION에 이미 저장된 경우 → 바로 반환 (캐싱)
- 없는 경우 → FastAPI AI 서버에 요약 생성 요청 후 저장
- 모든 모드 공통 제공

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "message": "AI 정리본 조회 성공",
  "data": {
    "session_id": 1,
    "ai_summary": "## 핵심 내용\n1. 고려 건국 (918년)...\n2. 무신정변 (1170년)...",
    "is_cached": true
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
