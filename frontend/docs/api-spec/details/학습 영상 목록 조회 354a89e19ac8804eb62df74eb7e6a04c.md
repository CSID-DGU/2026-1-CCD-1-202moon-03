# 학습 영상 목록 조회

API URL: /api/sessions/
App Name: Session
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP
URL 설명: 로그인 사용자의 학습 영상 목록 조회

## **기능 설명**

로그인한 사용자의 학습 영상 목록을 조회한다. 썸네일/제목/날짜/모드 포함.

## **BE 구현 주의 사항**

- 본인 세션만 조회 가능 (JWT user_id 기준 필터)
- 최신순 정렬 기본값
- ai_status가 done인 세션만 노출 or 전체 노출 정책 결정 필요
- 기능명세서 2.4.2: hover 시 모드별 다른 정보 → 프론트에서 mode 필드 사용

- **설명**:

```json
{
  "message": "학습 목록 조회 성공",

```
