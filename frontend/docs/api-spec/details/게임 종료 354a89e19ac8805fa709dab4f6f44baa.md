# 게임 종료

API URL: /api/sessions/{id}/game/end/
App Name: Game
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

게임 종료 시 학습 결과(총점/콤보/정확도/시청완료율)를 저장한다.

## **BE 구현 주의 사항**

- LEARNING_RESULT 생성 (세션당 1개, 재플레이 시 덮어쓰기 or 새로 생성 정책 결정)
- watch_rate: 0.0 ~ 1.0 (소수점)
- typing_accuracy: 0.0 ~ 1.0
- 집중호우 모드만 total_score / max_combo / typing_accuracy 의미 있음
- 피젯 모드는 watch_rate + quiz 결과만 저장

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body 예시**

```json
 {
  "watch_rate": 0.87,
  "total_score": 4200,          // 집중호우 모드만
  "max_combo": 15,              // 집중호우 모드만
  "typing_accuracy": 0.93,      // 집중호우 모드만
  "quiz_correct": 3,
  "quiz_total": 4
}
```
