# 온보딩 설문 저장

API URL: /api/auth/survey/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

회원가입 2단계로 온보딩 설문 답변을 저장하고 자극 강도(stimulation_level)를 자동 계산한다.

## **BE 구현 주의 사항**

- 문항은 5개 (question_number: 1~5)
- answer_value 기반으로 low/medium/high 자극 강도 자동 계산 후 USER.stimulation_level 업데이트
- 이미 설문 완료한 유저가 재요청 시 덮어쓰기 or 409 처리 정책 결정 필요
- 설문 완료 후 USER.is_tutorial_done은 별도 API에서 처리 (튜토리얼 후순위)
