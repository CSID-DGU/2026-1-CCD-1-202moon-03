# 환경설정 수정

API URL: /api/users/me/settings/
App Name: Users
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: PATCH
Type: HTTP

## **기능 설명**

피젯 스피너/키캡 전환키를 변경한다.

## **BE 구현 주의 사항**

- 허용 키값 목록 서버에서 화이트리스트 검증 권장
- 기능명세서 7.4.1: 기본값 alt키

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (JSON)**

```json
 {
  "fidget_toggle_key": "string"   // 예: "alt", "ctrl", "shift"
}
```

---

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "message": "환경설정이 변경되었습니다.",
  "data": {
    "fidget_toggle_key": "ctrl"
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
