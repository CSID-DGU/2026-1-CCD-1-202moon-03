# 새 비밀번호 설정

API URL: /api/auth/password/reset-confirm/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

이메일로 받은 토큰을 검증하고 새 비밀번호로 변경한다.

## **BE 구현 주의 사항**

- 토큰 만료 또는 이미 사용된 토큰이면 400 반환
- 새 비밀번호 / 확인 비밀번호 일치 검증
- 변경 완료 후 토큰 무효화 처리

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json"
}
```

### **Request Body (JSON)**

```json
 {
  "token": "string",
  "new_password": "string",
  "new_password_confirm": "string"
}
```

---

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

## Response Body 예시

- **설명**:

```json
{
  "message": "비밀번호가 변경되었습니다.",
  "data": {}
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    
    ```json
    # 400 Bad Request - 토큰 만료
    {
      "message": "재설정 링크가 만료되었습니다.",
      "data": {}
    }
    
    # 400 Bad Request - 비밀번호 불일치
    {
      "message": "비밀번호가 일치하지 않습니다.",
      "data": {}
    }
    
    # 400 Bad Request - 형식 오류
    {
      "message": "새 비밀번호 형식이 올바르지 않습니다.",
      "data": {}
    }
    ```
