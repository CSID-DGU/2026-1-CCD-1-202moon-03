# 비밀번호 변경

API URL: /api/users/me/password/
App Name: Users
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: PUT
Type: HTTP

## **기능 설명**

기존 비밀번호를 검증한 후 새 비밀번호로 변경한다. 변경 후 토큰을 재발급한다.

## **BE 구현 주의 사항**

- 기존 비밀번호 일치 여부 먼저 검증
- 새 비밀번호 형식 검증 (8자 이상)
- 새 비밀번호 / 확인 불일치 시 400 반환
- 변경 완료 후 기존 refresh token 블랙리스트 처리 후 새 토큰 재발급
→ 로그인 유지

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (JSON)**

```json
 {
  "current_password": "string",
  "new_password": "string",
  "new_password_confirm": "string"
}
```

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

### Response Body (JSON)

- **설명**:

```json
{
  "message": "비밀번호가 변경되었습니다.",
  "data": {
    "access": "eyJhbGci...",
    "refresh": "eyJhbGci..."
  }
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**
