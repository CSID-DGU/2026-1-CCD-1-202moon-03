# 로그아웃

API URL: /api/auth/logout/
App Name: Auth
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: POST
Type: HTTP

## **기능 설명**

refresh 토큰을 블랙리스트에 등록하여 로그아웃 처리한다.

## **BE 구현 주의 사항**

- djangorestframework-simplejwt의 TokenBlacklist 앱 사용
- refresh token을 body로 받아 블랙리스트 처리
- access token은 만료 전까지 유효하나 짧은 만료시간으로 보완

---

## **Request (요청)**

### **Headers**

요청 시 포함될 HTTP 헤더 정보 (Content-Type, Authorization 등)

```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer {access_token}"
}
```

### **Request Body (JSON)**

```json
 {
  "refresh": "string"
}
```
