# 퀴즈 다시 풀기

API URL: /api/sessions/{id}/quiz/retry/
App Name: Quiz
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP

## **기능 설명**

학습 결과 화면에서 퀴즈를 다시 풀기 위해 해당 세션의 전체 퀴즈 목록을 반환한다.
기존 답변 기록은 초기화하지 않음 (새 QUIZ_ATTEMPT 추가).

## **BE 구현 주의 사항**

- 기능명세서 6.1.4: 퀴즈 다시 풀기 — 모든 모드 공통
- 기존 QUIZ_ATTEMPT는 유지, 새 답변은 추가 기록
- explanation 포함하지 않음 (다시 풀기이므로 정답 숨김)
