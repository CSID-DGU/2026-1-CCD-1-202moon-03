# 전체 학습 기록 조회

API URL: /api/users/me/history/
App Name: Analytic
BE 개발 상태: 시작 전
BE 담당: 수빈 임
FE 개발 상태: 시작 전
HTTP Method: GET
Type: HTTP
URL 설명: 전체 학습 기록 목록 조회 (마이페이지)

## **기능 설명**

마이페이지에서 세션별 학습 기록(점수/완료율/정확도)을 목록으로 조회한다.

## **BE 구현 주의 사항**

- 기능명세서 7.3.1: 세션별 점수/완료율/정확도 목록 조회
- LEARNING_RESULT가 있는 세션만 조회 (완료된 세션)
- 최신순 정렬

## Response (응답)

### 성공 응답 (Status)

- **설명**: API 호출 성공 시 예상되는 HTTP 상태 코드
- **기입 내용**: 200 - OK

### Response Body (JSON)

- **설명**:

```json
{
  "message": "학습 기록 조회 성공",
  "data": [
    {
      "session_id": 1,
      "title": "한국사 강의 1강",
      "mode": "rain",
      "thumbnail_url": "https://...",
      "watch_rate": 0.87,
      "total_score": 4200,
      "typing_accuracy": 0.93,
      "quiz_correct": 3,
      "quiz_total": 4,
      "completed_at": "2025-04-01T14:00:00Z"
    }
  ]
}
```

### 오류 응답 (Status)

- **설명**: API 호출 실패 시 예상되는 HTTP 상태 코드 및 유형
- **기입내용:**
    - 401 - 인증 필요
    - 404 - 요약 없음
    - 409 - 아직 생성 중
    - 500 - 서버 내부 오류

### 오류 응답 Body (JSON)

- **설명**: 오류 발생 시 서버로부터 받는 에러 메시지 및 상세 정보및 응답데이터 JSON 예시
- **기입 내용**:
    
    ```json
    {
      "message": "아직 AI 정리본 생성이 완료되지 않았습니다.",
      "data": {
        "status": "processing"
      }
    }
    ```
